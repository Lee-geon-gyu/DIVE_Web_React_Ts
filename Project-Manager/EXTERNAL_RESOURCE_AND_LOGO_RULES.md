## 외부 사이트 정보 및 로고 사용 규칙

UI/UX 레퍼런스, AI 도구, 디자인 리소스, 웹 라이브러리를 소개할 때 각 카드에 다음 정보를 표시한다.

- 공식 로고 또는 안전한 대체 아이콘
- 사이트 또는 서비스 이름
- 한 줄 소개
- 공식 사이트 주소
- 카테고리
- 무료 또는 유료 여부
- 공식 사이트 방문 버튼
- 정보 확인일

각 카드의 공식 사이트 버튼은 실제 주소로 연결하며, 외부 링크에는 `target="_blank"`와 `rel="noopener noreferrer"`를 적용한다.

### 정보 검증 규칙

절대로 존재하지 않는 사이트, 서비스, 기능, 가격, 라이선스 또는 URL을 임의로 생성하지 않는다.

외부 서비스를 데이터에 추가하기 전에 다음 항목을 확인한다.

1. 공식 사이트가 실제로 접속 가능한지 확인한다.
2. 사이트명과 URL이 일치하는지 확인한다.
3. 공식 사이트 또는 공식 문서에서 서비스의 주요 기능을 확인한다.
4. 가격과 무료 플랜 정보는 공식 가격 페이지를 기준으로 확인한다.
5. 라이선스 정보는 공식 라이선스 또는 이용약관 페이지에서 확인한다.
6. 확인할 수 없는 정보는 추측해서 작성하지 않는다.
7. 정보가 불확실한 경우 `확인 필요` 또는 `공식 사이트에서 확인`으로 표시한다.
8. 개인 블로그나 광고성 게시글을 공식 정보처럼 사용하지 않는다.
9. 서비스가 종료되었거나 공식 사이트가 접속되지 않는 경우 기본 목록에서 제외한다.
10. 마지막으로 정보를 확인한 날짜를 데이터에 기록한다.

Codex가 인터넷에 접근할 수 없거나 현재 정보를 검증할 수 없는 환경이라면 실제 정보처럼 작성하지 않는다. 이 경우 임의의 사이트를 생성하지 말고 검증이 필요한 항목을 명확히 표시한 샘플 데이터만 작성한다.

```ts
interface ResourceItem {
  id: string;
  title: string;
  description: string;
  officialUrl: string;
  logoUrl?: string;
  category: string;
  tags: string[];
  isFree?: boolean;
  pricing?: string;
  license?: string;
  sourceUrl?: string;
  verified: boolean;
  verificationStatus: "verified" | "needs-review" | "unavailable";
  lastCheckedAt?: string;
}
```

`verified`가 `false`인 콘텐츠에는 카드 상단에 `정보 확인 필요` 배지를 표시하고, 운영용 데이터로 확정하지 않는다.

### 로고와 이미지 사용 규칙

외부 서비스의 로고를 사용할 때 다음 기준을 지킨다.

1. 공식 사이트가 직접 제공하는 로고 또는 브랜드 리소스를 우선 사용한다.
2. 브랜드 가이드라인이나 이용 조건이 있다면 해당 조건을 따른다.
3. 공식 로고 파일의 사용 권한을 확인할 수 없는 경우 로고를 직접 복사하거나 재배포하지 않는다.
4. 구글 이미지 검색, 블로그, Pinterest 등에서 가져온 이미지를 사용하지 않는다.
5. 로고를 임의로 수정하거나 색상, 비율, 형태를 변형하지 않는다.
6. 로고를 사이트가 해당 브랜드와 공식 제휴한 것처럼 보이게 사용하지 않는다.
7. 로고를 사용할 수 없는 경우 서비스명의 첫 글자 또는 카테고리 아이콘으로 만든 대체 이미지를 사용한다.
8. 외부 로고는 장식이나 홍보 목적이 아니라 해당 서비스를 식별하기 위한 최소한의 크기로만 표시한다.
9. 로고 이미지가 로드되지 않으면 대체 아이콘과 서비스명을 표시한다.
10. 각 서비스와의 제휴 또는 공식 관계가 없다는 안내 문구를 푸터 또는 정보 페이지에 표시한다.

안내 문구 예시:

“본 사이트는 학습과 정보 제공을 목적으로 외부 서비스를 소개합니다. 표시된 서비스명과 로고의 권리는 각 소유자에게 있으며, 본 사이트는 별도로 표시되지 않는 한 해당 서비스와 공식적인 제휴 관계가 없습니다.”

### 이미지 및 콘텐츠 저작권 규칙

외부 사이트의 화면 캡처, 상세 설명, 소개 문구를 그대로 복사하지 않는다.

- 공식 사이트의 문장을 장문으로 복사하지 않는다.
- 서비스 설명은 공식 정보를 바탕으로 새롭게 요약한다.
- 다른 사이트의 카드 디자인이나 페이지 구조를 그대로 복제하지 않는다.
- 사이트 화면 캡처를 썸네일로 무단 사용하지 않는다.
- 직접 제작한 그래픽, 사용 허가가 명확한 이미지 또는 단순한 대체 아이콘을 사용한다.
- Unsplash, Pexels 등 외부 이미지도 실제 라이선스와 출처 표기 조건을 확인한다.
- 라이선스가 불분명한 이미지는 사용하지 않는다.
- 오픈소스 아이콘과 라이브러리는 해당 라이선스 정보를 프로젝트 문서에 기록한다.
- 코드 예제는 직접 작성하거나 공식 문서의 라이선스가 허용하는 범위에서 사용한다.
- 공식 문서의 코드를 활용한 경우 출처 URL과 라이선스를 함께 기록한다.

### 관리자 검수 단계

외부 리소스 데이터는 바로 사용자에게 노출하지 않고 다음 상태로 관리한다.

- `draft`: 작성 중
- `needs-review`: 사실과 권리 관계 확인 필요
- `published`: 검증 완료
- `archived`: 서비스 종료 또는 정보 만료

`published` 상태인 콘텐츠만 일반 사용자 화면에 표시한다.

콘텐츠를 추가하거나 수정할 때 다음 검수표를 사용한다.

- 공식 사이트 존재 여부
- 공식 URL 정확성
- 서비스명 정확성
- 설명의 사실 여부
- 가격 정보 확인
- 라이선스 정보 확인
- 로고 사용 가능 여부
- 출처 URL 기록
- 마지막 확인일 기록
- 제휴 관계로 오해할 표현이 없는지 확인

자동 검증만으로 저작권과 상표권의 적법성을 확정할 수 없으므로, 권리 관계가 불분명한 콘텐츠는 자동으로 게시하지 않는다. 최종 공개 전에는 사람이 직접 공식 이용약관과 브랜드 가이드라인을 확인하도록 한다.
